## Project Introduction

This project is a simple **Sales Management System database** created for the **Database Systems** course.  
It is designed to store and manage basic information about customers, products, suppliers, orders, and payments.

The database uses multiple related tables with primary and foreign keys to show how a real sales system can be organized.  
It also includes sample data and SQL queries to practice common database operations.

The goal of this project is to understand database design, relationships between tables, and basic SQL commands.

---

## Project Objectives

• Design a normalized relational database for a sales system  
• Apply primary keys and foreign keys correctly  
• Implement customer specialization using separate tables  
• Ensure data integrity and consistency  
• Practice CRUD operations (INSERT, UPDATE, DELETE)  
• Use SQL functions, joins, grouping, and subqueries  
• Translate ERD and relational model into SQL implementation  

---

## Database Tables

The system consists of the following tables:

• Customers – stores customer personal and contact information  
• RegularCustomer – stores discount information for regular customers  
• VIPCustomer – stores membership level and bonus points for VIP customers  
• Suppliers – stores supplier details  
• Categories – stores product categories  
• Products – stores product details and pricing  
• Orders – stores customer orders  
• OrderItems – links orders with products and quantities  
• Inventory – tracks product stock movement  
• Payments – stores payment information  
• Shipments – stores delivery and tracking details  

---

## SQL Features Demonstrated

The project includes examples of:

• String functions (LENGTH, LOWER, INSTR, SUBSTRING)  
• Numeric functions (ROUND, TRUNCATE)  
• Date functions (SUBDATE, DATE_ADD, TIMESTAMPDIFF)  
• Joins (INNER JOIN, LEFT JOIN)  
• Aggregation (SUM, AVG, GROUP BY, HAVING)  
• Subqueries using IN and comparison operators  
• Data modification (INSERT, UPDATE, DELETE)
